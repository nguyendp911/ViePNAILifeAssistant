# ViePN AI Life V3.2

## Changes
- Accounts: `VIEPN_ACCOUNTS_JSON` is a JSON array of `{id, displayName, token}`; `id` limited to alphanumeric / underscore / hyphen. Separate tokens, no self signup.
- Storage: `VIEPN_DATA_FILE` remains available in legacy mode; configured accounts use sibling `users/<id>.json`. Each export is tenant scoped. Writes are serialized per tenant; first load deduplicated.
- HTTP: `GET /v1/me` returns only id and display name, no tokens. Other APIs remain backward compatible.
- iOS: ChatHistory filenames are SHA-256 fingerprints of (gateway URL + token) so changing accounts does not show another user's chat. Token remains Keychain-protected; file uses Complete File Protection.
- Testing: unit tests and end-to-end tests for separate accounts, unauthorized calls, restart persistence and exports.

## Release blockers
- No password reset, token rotation, rate limiting, 2FA, account lifecycle or OAuth 2.0 yet.
- JSON per user is for a small prototype and NOT multi-process safe. Use PostgreSQL transactional persistence and migrations for production.
- Scheduler scans only users loaded in process; restart requires loading tenant accounts proactively.
- iOS requires macOS Xcode CI and device QA.
- Chat history previously created in V3.1 global file is not automatically migrated.
