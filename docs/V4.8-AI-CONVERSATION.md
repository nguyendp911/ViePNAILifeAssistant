# ViePN AI Life V4.8 — AI Conversation 2.0

## Phạm vi V4.8

**AI → AI Assistant 2.0** có hội thoại nhiều lượt, bộ chọn nhà cung cấp và model lấy từ Gateway, nút sao chép và đọc tiếng Việt bằng công cụ TTS có sẵn trong iOS. Có thể bật *Tự đọc* thủ công, mặc định tắt.

- Lịch sử chat vẫn lưu **trên iPhone**, phân tách theo fingerprint của URL Gateway + token, bảo vệ bằng Complete File Protection và không sao lưu theo ChatHistory hiện có. Không tự đồng bộ lịch sử lên Gateway.
- Mỗi lần gửi, ứng dụng chỉ gửi tối đa **12 lượt hội thoại trước đó**, mỗi lượt tối đa 3.000 ký tự và tổng tối đa 12.000 ký tự, cộng với câu hỏi hiện tại (tối đa 5.000 ký tự). Hỏi AI không tự đưa bộ nhớ cá nhân, tài liệu, nhiệm vụ, Google Calendar, thông tin từ app khác vào prompt.
- Bấm biểu tượng trang giấy/bút ở góc trên bên phải để **xóa lịch sử chat cục bộ và bắt đầu hội thoại mới**. Không có trang quản lý đa hội thoại trong bản này.
- TTS dùng `AVSpeechSynthesizer` trên iPhone, giọng `vi-VN`, tối đa 2.500 ký tự/lượt; không gửi yêu cầu phát âm đến bên thứ ba trong code.
- Có ghi nhận lỗi kết nối và giữ lại văn bản đang soạn để thử lại, không lưu một lượt chưa nhận được phản hồi AI thành lịch sử hợp lệ.
- Chưa triển khai **streaming token trực tiếp**, công cụ gọi hành động tự động, gợi nhớ trong chat mặc định, hay bộ chọn voice cloud.

## Cấu hình Gateway

Những biến cấu hình nằm **trên server** (không nhập API key vào iPhone):

| Biến | Ý nghĩa |
|---|---|
| `AI_API_URL` | HTTPS OpenAI-compatible Chat Completions endpoint |
| `AI_API_KEY` | API key cho endpoint đó |
| `AI_MODEL` | Model mặc định được phép |
| `GEMINI_API_KEY` | Google Gemini API key (tùy chọn) |
| `GEMINI_MODEL` | Model Gemini mặc định có sẵn với key (tùy chọn) |
| `VIEPN_AI_PROVIDERS_JSON` | Tùy chọn: thêm tối đa 8 nhà cung cấp với danh sách model cho phép, key riêng trên Gateway |

Nếu muốn có nhiều model cho một provider, dùng danh sách JSON ở biến `VIEPN_AI_PROVIDERS_JSON`:

```json
[
  {
    "id": "my-openai",
    "name": "OpenAI",
    "kind": "openai",
    "endpoint": "https://api.openai.com/v1/chat/completions",
    "key": "SERVER_ONLY_KEY",
    "models": ["model-id-enabled-1", "model-id-enabled-2"]
  },
  {
    "id": "my-gemini",
    "name": "Google Gemini",
    "kind": "gemini",
    "key": "SERVER_ONLY_KEY",
    "models": ["gemini-model-id-enabled"]
  }
]
```

Các model ID phía trên là **ví dụ placeholder**, không phải danh sách model đang hoạt động đã được xác minh. Hãy nhập model có quyền sử dụng theo API key thực tế của bạn. Đừng commit hoặc chia sẻ file chứa API key thật.

Chỉ Gateway chọn nhà cung cấp từ danh sách cho phép; người dùng không thể tự chỉ định endpoint hoặc khóa bí mật qua API. Gemini dùng native REST `generateContent`, còn loại `openai` dùng JSON Chat Completions. Tất cả đều yêu cầu kết nối HTTPS.

## REST API V4.8

`GET /v1/ai/providers`: bắt buộc Bearer token của tài khoản, trả về tên provider, loại provider và các model được phép. **Không bao giờ trả về key hoặc URL backend**.

`POST /v1/chat`: bắt buộc Bearer token, tương thích request V4.7 chỉ có `message`. V4.8 nhận thêm `history`, `providerId`, `model`.

```json
{
  "message": "Tiếp tục giải thích ví dụ đó",
  "providerId": "my-gemini",
  "model": "gemini-model-id-enabled",
  "history": [
    {"role": "user", "content": "AI là gì?"},
    {"role": "assistant", "content": "AI là lĩnh vực phát triển hệ thống thông minh."}
  ]
}
```

History chỉ chấp nhận role `user` và `assistant`; không chấp nhận `system`/tools từ client. Nếu provider/model không thuộc danh sách server sẽ trả lỗi. Nếu không cấu hình AI, trả kết quả `configured:false` (không gửi ra bên ngoài).

Kết quả:
```json
{
  "reply": "AI có thể học từ dữ liệu...",
  "configured": true,
  "provider": "my-gemini",
  "model": "gemini-model-id-enabled"
}
```

`/v1/chat` không lưu nhật ký lên server, không lưu bộ nhớ cá nhân, không tự gửi email, gọi Google hoặc thực hiện công việc. Các API hỏi AI theo ngữ cảnh V4.4 vẫn riêng biệt, có phạm vi chia sẻ và sự đồng ý riêng.

## Kiểm thử, hạn chế và phát hành

- Kiểm thử TypeScript, Unit tests cho OpenAI/Gemini mock, quota context, từ chối role system, provider/model không được cho phép, không lộ key, HTTP auth và lỗi cấu hình. Chạy `cd gateway && npm install && npm run check && npm test && npm run test:api`.
- GitHub Actions macOS biên dịch iOS; workflow tạo **IPA chưa ký**. Chưa xác minh tài khoản AI thực tế, chất lượng đọc tiếng Việt trên iPhone hoặc streaming.
- Cần cấu hình HTTPS Gateway và restart sau khi thêm hoặc thay model. iOS cần truy cập internet để dùng Chat API.
- Không thay đổi Bundle ID, Apple entitlement hay giới hạn App ID Apple ID miễn phí. IPA có Share Extension và vẫn cần profile tương thích để ký 7 ngày.
