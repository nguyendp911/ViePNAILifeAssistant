# ViePN AI Life V3.1 — Premium Minimal AI UI/UX

## Objectives
- Native SwiftUI, iOS 17+, Vietnamese-first.
- Five tabs: **Home, AI, Actions, Library, Profile**.
- Adaptive dark/light surfaces, gradient hero, indigo/cyan highlights, 16–25pt rounding, 44pt+ tap targets.
- Keep important actions visible; separate suggestions from actual execution.

## Screen map

| Tab | Main content | Primary action |
| --- | --- | --- |
| Home | Greeting, hero, task/memory/pending metrics, quick shortcuts, task checklist | Start AI chat / add task |
| AI | Empty-state prompts, message bubbles, microphone and send controls, on-device saved history | Ask AI |
| Actions | Approval queue across workflows/actions/automation, explicit approve/reject | Review requests |
| Library | Segmented Documents / Notes / Memory, document OCR / PDF, approved memories | Import document |
| Profile | Gateway, security, memory, Skills, scheduled reminders | Review access |

## Design tokens
- `LifeTheme.accent` indigo (#6663F5 approx), cyan accent (#30C7EB approx).
- Surfaces use adaptive material and semantic text colors, not black-on-black hard-coded text.
- Responsive `LazyVGrid` for shortcuts and 3-up metrics; accommodate iPhone width.
- Text sizes use dynamic type; controls have meaningful accessibility labels where applicable.

## UX safety and privacy
- Never automatically execute a proposed action from chat.
- Approve/reject buttons visible on each pending step.
- App unlock remains system device authentication; gateway token stored in Keychain.
- Conversation history: last 100 lines stored in application support with iOS complete file protection, excluded from device backups; new conversation clears it.
- Existing API documents and memory remain on configured gateway; this is **not** a production multi-user backend.

## Implementation files
- `DesignSystem.swift`: visual tokens, cards, backgrounds, metrics and shortcuts.
- `ContentView.swift`: app shell, five-tab routing, premium Home/AI screens.
- `HubViews.swift`: Actions and Profile landing experiences.
- `LibraryView.swift`: Documents / Notes / Memory navigation.
- `ChatHistory.swift`: local protected chat store.

2. Dynamic type XL / accessibility largest, VoiceOver and keyboard focus.
3. Device lock then reopen; history must be inaccessible until unlocked.
4. Voice recognition permission denial and airplane mode.

6. End-to-end gateway HTTPS requests, credentials, and approval flows.

No generated UI reference artwork is required at runtime; all visual elements are native SwiftUI.
