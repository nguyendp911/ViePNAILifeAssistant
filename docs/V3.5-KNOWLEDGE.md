# V3.5 Knowledge and grounded Q&A

Flow: local PDF/TXT selection → local extraction → explicit save → POST /v1/documents → tenant database → chunks → lexical retrieval → optional AI synthesis → cited excerpts.

Security: do not execute document instructions; restrict each request to authenticated tenant; no external URLs fetched; original PDF stays on device. Data isolation for tenancy uses existing tenant boundary. Export includes raw document chunks (sensitive).

Limitations: no actual embeddings/vector database, no OCR for scanned PDFs in this page, no source fact-checker, no automatic summarization validation; do not equate the source excerpts with ground truth.
