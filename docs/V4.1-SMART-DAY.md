# V4.1 – Smart Day

## What shipped
The authenticated **Smart Day** screen groups local tasks by Vietnamese local-day boundary and shows due-today, overdue, tomorrow, open/completed counts, outstanding manual approvals, and enabled recurring automations due within the next 48 hours. It does not perform actions or call AI, email, or Google Calendar.

Open **Home → Smart Day · Bản tin hôm nay**. Mark a task complete or go to **Action Center** to examine approval requests. The interface re-fetches on opening and pull-to-refresh.

## API
`GET /v1/briefing?offsetMinutes=420` (Bearer auth required). Offset is integer minutes east of UTC in [-720,840], and must be supplied by the device at request time. A 400 error is returned for invalid offsets; 401 for missing/invalid authorization.

Example response:
```json
{
  "generatedAt": "2026-11-13T04:00:00.000Z",
  "localDate": "2026-11-13",
  "timezoneOffsetMinutes": 420,
  "summary": {
    "openTasks": 3,
    "completedTasks": 1,
    "overdue": 1,
    "dueToday": 1,
    "upcoming": 1,
    "pendingApprovals": 2,
    "scheduledSoon": 1
  },
  "approvals": {"actions": 1, "workflows": 1, "automations": 0, "total": 2},
  "priorities": [],
  "upcomingAutomations": []
}
```
`priorities` includes at most 12 records ordered overdue → today → next day → other; `upcomingAutomations` at most 5. Counts represent all underlying matching records. Remote data is scoped to the authenticated tenant; the response excludes secrets, full memory entries and documents.

## Safeguards
- Server calculation is deterministic, **read-only** and uses existing tenant state.
- Approvals are never accepted automatically. The Action Center retains the existing per-step confirmation requirement.
- No location permissions, new iOS entitlements, scheduled background execution, external AI calls, or provider key exposure.
- Currently, upcoming means due on the **next local calendar day**, and date-free / farther-future tasks are categorized as undated/other for prioritization. This does **not** reschedule their actual `dueAt`.
- `offsetMinutes` is a fixed UTC offset sampled by the device when requesting. A future timezone-aware calendar implementation would need an IANA timezone name to handle DST transitions within a target day.
- Sign the IPA separately; free Apple IDs still have Apple-enforced App ID quotas, and the embedded Share Extension needs its own provisioning profile.

## Validation
Run `cd gateway && npm install && npm run check && npm test && npm run test:api`.
The iOS workflow uses macOS + XcodeGen to produce an **unsigned** iPhone IPA; it is not equivalent to a signed/tested App Store release.
