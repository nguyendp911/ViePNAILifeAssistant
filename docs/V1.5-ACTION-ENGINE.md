# ViePN AI Life V1.5 — Action Engine & Document API

## Trust boundary
The iOS app never includes an AI-provider secret. The gateway requires bearer authentication and HTTPS at its reverse proxy. No LLM output is executed automatically. Each workflow step is a fixed, validated operation requiring explicit user approval. No arbitrary JavaScript, shell commands, network requests, payments, email sending, or third-party account actions are supported.

## Workflow schema
POST `/v1/workflows`

```json
{
  "title":"Chuẩn bị cuộc họp",
  "steps":[
    {"kind":"create_note","payload":{"title":"Nội dung họp","content":"Kế hoạch tuần"}},
    {"kind":"create_task","payload":{"title":"Kiểm tra nội dung họp","dueAt":null}}
  ]
}
```

200/201 response: workflow with `id`, `title`, `currentStep`, `status`, `steps`, `history`. First step starts at `awaiting_approval`; later steps are `pending`.

GET `/v1/workflows` lists workflows. GET `/v1/notes` lists approved notes.

POST `/v1/workflows/{workflowId}/steps/{stepId}/approve` approves and executes exactly the current step, then advances. POST `/v1/workflows/{workflowId}/steps/{stepId}/reject` rejects and stops the workflow. Retries after resolution are rejected to avoid repeated execution. A workflow holds at most 10 steps.

### Data structures
- `workflows`: array of workflow state machines, step states and event history.
- `notes`: persisted text notes after approval.
- `tasks`, `memories`, `actions`: V1.0 collections remain compatible.

The JSON store is **single-user development only**, not suitable for multi-user commercial workloads. Production requires database transactions, scoped users, durable idempotency keys, encryption, rate limits, separate audit retention, and safe retry/recovery on crashes. In particular, a crash between executing a step and persisting the new state may require reconciliation. No automatic retry is implemented.

## iOS document workflows
- Photo OCR via Vision (V1.0).
- Import a *text-based* PDF using PDFKit, limit 25MB / 150 pages; scanned PDF without text is not yet OCR'd.
- Export text to a paginated PDF through UIGraphicsPDFRenderer locally. Share the created PDF via system ShareLink.
- No PDF file is automatically sent to the gateway. AI summarization explicitly sends at most 4,500 characters from the editor, as in V1.0.
- Office Word (.docx), Share Extension (incoming from other apps), App Intents, and live Calendar API are not yet implemented.

## API authentication
`Authorization: Bearer <VIEPN_GATEWAY_TOKEN>` on all `/v1/*` endpoints. For a public deployment, use TLS reverse proxy and isolate the internal gateway. Never commit `.env`.

## iOS quick test
1. Configure secure gateway in **Cá nhân** tab.
2. In **Hành động**, create a 2-step workflow (note → task).
3. Verify no note exists before approval.
4. Approve first step; verify note appears but task does not.
5. Approve second step; verify task appears on Home.
6. Repeat approval request; gateway rejects it.
7. In **Tài liệu**, import PDF with selectable text, export new PDF, and share via iOS UI.
