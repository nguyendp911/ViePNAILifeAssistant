# V3.4 integration / acceptance checklist

## Implemented
- Native Share Extension for plain text or one HTTP(S) URL. No cookies, HTML extraction, other apps' private data, or automatic content scraping.
- App Group staging with a 7-day retention cap, 20 item maximum, text length cap 8,000 characters. No token in shared preferences.
- Inbox in Library; user reviews and sends a workflow, then approves in Action Center.
- App Intent to open ViePN AI Life via Siri/Shortcuts (no privileged action automation).
- Foreground sync when session becomes active; simple 60-second throttle; manual refresh remains.

## Setup before installation
1. Register App ID `com.viepn.ailife` and extension ID `com.viepn.ailife.share` in Apple developer portal.
2. Enable App Groups on both IDs and create/associate `group.com.viepn.ailife`.
3. Create a **separate** provisioning profile for the application and extension and sign both.
4. Deploy HTTPS Gateway and PostgreSQL for real accounts. Do not put provider AI API keys in IPA.
5. Test Share → Inbox → Edit → Submit → Action Center approve → Note appears on device.

## Not completed
- Full Xcode/macOS build, signing, on-device share-sheet runtime verification.
- Generalized offline mutation queue and conflict resolution (currently online-first).
- Share Extension files and photos, direct Calendar/Email OAuth, push notifications, server-driven background sync.
- End-to-end PostgreSQL integration and production security review.

## Privacy note
Shared text remains in App Group UserDefaults pending import and is readable by the main application and its extension. Do not treat App Group preferences as encrypted secret storage; for sensitive files implement encrypted staging and expiry before release.
